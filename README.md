### Projekte

**[josija-nydegger.github.io](https://github.com/josija-nydegger/josija-nydegger.github.io)**
Meine persönliche Website mit Lebenslauf, Arbeiten, Blog und kleinen Web-Tools für die Statik. Schlicht gehalten mit Jekyll, zweisprachig (Deutsch/Englisch), ohne Tracker.
→ [josija-nydegger.ch](https://josija-nydegger.ch)

**[QR-tool](https://github.com/josija-nydegger/QR-tool)**
Einweg-Datenübertragung vom Computer aufs Smartphone ohne Netzwerk, über eine schnelle Folge von QR-Codes. Mit optionaler AES-256-GCM-Verschlüsselung und Fountain-Codes, sodass verpasste Bilder keine Rolle spielen. Läuft vollständig im Browser.
→ [Demo (Empfänger)](https://josija-nydegger.ch/QR-tool/QR-Reader.html)

**[weather-bot](https://github.com/josija-nydegger/weather-bot)**
Telegram-Bot, der jeden Morgen eine Wettermeldung für Bern verschickt: Temperatur, Regenwahrscheinlichkeit und -menge, Sonnenauf- und -untergang. Python, OpenWeatherMap und GitHub Actions.
